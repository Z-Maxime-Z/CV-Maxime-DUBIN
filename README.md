# CV Maxime DUBIN

Site en ligne : [https://z-maxime-z.github.io/CV-Maxime-DUBIN/](https://z-maxime-z.github.io/CV-Maxime-DUBIN/)

Mon CV en ligne : une page unique (`index.html`) qui affiche mes expériences, formations, compétences, langues, certifications, projets, liens et centres d'intérêt.

## Utilisation

Ouvrez `index.html` dans un navigateur pour voir le CV.

## Modifier les données

Les informations du CV sont stockées dans la page, dans le bloc `<script type="application/json" id="cv-data">`. Les ajouts, modifications et suppressions se font avec les formulaires de la version publiée dans Claude, qui se sauvegarde elle-même.

La copie hébergée ici est un instantané en lecture seule : l'enregistrement par formulaire ne fonctionne que dans Claude.
